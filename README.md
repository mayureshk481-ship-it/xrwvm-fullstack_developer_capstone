# Cars Dealership - Full-Stack Web Application

**Repository name:** xrwvm-fullstack_developer_capstone
**Project name:** Cars Dealership Full-Stack Application

## About
A full-stack web application for Cars Dealership, a national car retailer in the U.S.
Users can view dealership branches, filter them by state, read reviews, and post reviews.

## Tech stack
- Frontend: React, HTML, CSS
- Backend: Django, Node.js/Express, Flask
- Databases: MongoDB, SQLite
- Deployment: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions
